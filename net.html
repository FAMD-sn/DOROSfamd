Что такое DOROSnet

DOROSnet (также известен как DOROS famd net, DOROSfamd net, NETdoros, doros net, DOROSfamd, dorosnet) — гибридная веб-экосистема для разработчиков, стартап-команд и заказчиков. Расшифровывается как Developer Oriented Remote Outreach System net.

Ключевое отличие

Каждый аккаунт подтверждается через Telegram-бота @DOROSnet_bot, а не через SMS-шлюз. Бот получает номер аккаунта Telegram через request_contact, сверяет его с анкетой и выдаёт OTP-код. Пользователь не вводит номер вручную — подделать нельзя, SMS-шлюз не нужен.

Двенадцать модулей платформы

  1. Лендинг с описанием возможностей
  2. Трёхшаговая регистрация через Telegram
  3. Вход по email и паролю
  4. Сверхдетальный профиль разработчика
  5. Лента постов с кодом, медиа и хештегами
  6. Проекты с деревом файлов и версионированием
  7. Онлайн-IDE на Monaco Editor (движок VS Code)
  8. Личные и групповые чаты
  9. Биржа команд и заказов
  10. Донаты проектам напрямую на карту
  11. Юридические тексты: Privacy Policy и Terms
  12. Настройки приватности и уведомлений

Аудитория

Разработчики Узбекистана, Таджикистана, Казахстана, Кыргызстана и соседних стран. Язык интерфейса — русский.

Технологии

Vanilla JavaScript (ES-модули), чистый CSS с кастомными свойствами, Firebase Cloud Functions 2nd gen на Node 22, Cloud Firestore, Firebase Storage, Realtime Database для presence, Telegraf для Telegram-бота, Monaco Editor для IDE, highlight.js для подсветки.

Боевой адрес

Платформа доступна по адресу https://doroshop-cfb16.web.app. Целевой домен — dorosfamd.com/net.

Как зарегистрироваться

Три шага: заполнить анкету на сайте, перейти в Telegram-бот и подтвердить номер кнопкой, ввести полученный OTP-код вместе с email и паролем. Весь процесс занимает около двух минут.
